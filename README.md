# OR Learning Lab — Етап 1. UI/UX-дизайн

Статичний сайт українською мовою для учнів 10–11 класів. HTML, CSS і JavaScript розділено за файлами; немає сторонніх JS-бібліотек або бекенду.

## Структура

- `index.html` — семантична HTML5-сторінка;
- `assets/styles.css` — адаптивний дизайн та стилі друку;
- `assets/app.js` — інтерактивний чекліст із локальним збереженням;
- `assets/logo.svg`, `assets/favicon.svg` — векторні іконки.

## Розміщення на GitHub Pages

1. Створіть новий репозиторій або папку `uiux-stage-1` у чинному репозиторії.
2. Завантажте **весь вміст** цієї папки, зберігаючи відносні шляхи до `assets/`.
3. У Settings → Pages виберіть гілку `main`, `/ (root)` (якщо це окремий репозиторій).
4. Для чинного репозиторію `ort-project-catalog` завантажте папку `uiux-stage-1` в корінь, не замінюючи головний `index.html`. Адреса буде `https://rybakolha.github.io/ort-project-catalog/uiux-stage-1/` після публікації.

## Додавання в Moodle

У курсі додайте ресурс **URL / Посилання**, вкажіть адресу опублікованої сторінки. Для здавання результатів створіть окрему діяльність **Завдання** з полем для посилання на Figma та звіт.

## Обмеження

Чекліст зберігається лише у localStorage поточного браузера і **не передає** інформацію до Moodle. Друк/PDF виконується штатними можливостями браузера. Після публікації перевірте поведінку на реальних пристроях.
